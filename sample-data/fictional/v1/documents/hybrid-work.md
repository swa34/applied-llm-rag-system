# Fictional hybrid work policy

This policy is invented for the Northbridge Learning Institute demonstration. Northbridge Learning Institute is fictional; this document does not describe any real organization's rules.

## Hybrid schedule

Employees whose roles are approved for hybrid work may work remotely for up to two days per week. The employee's manager approves the hybrid work agreement before the schedule begins.

## Temporary remote locations

Ordinary remote work must take place in the state of the employee's primary worksite. Working temporarily from another state requires approval from both the employee's HR partner and a payroll specialist before the out-of-state work begins.

## Home workspace support

Northbridge supplies an approved hybrid employee with a laptop and headset. The institute does not reimburse recurring home internet charges or household utility costs.
